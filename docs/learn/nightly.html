Refresher: what a percentile bootstrap band is

Resample the data with replacement many times, recompute the quantity each time, and take the 5th and 95th percentiles of those recomputed values as the band. If the method is honest, that band should contain the true value in about 90% of repeated experiments, which is what the coverage test counts. See Efron and Tibshirani, An Introduction to the Bootstrap (Chapman & Hall, 1993), ch. 13.
