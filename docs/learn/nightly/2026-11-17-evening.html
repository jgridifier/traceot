Reading only the published summary tables, the false-attribution misses look like ordinary sampling noise, not bias: on skew_struct the signed composition piece is 1.7–3.2% of its absolute size, and its absolute size falls about √10 when rows grow 10×. A noisy-but-unbiased piece will always miss a fixed absolute bar at small n. So the proposed fix is in what TRACE reports: zero the composition piece when its 90% bootstrap band covers 0, and move it into structure so the two still add up to the total. Bars stay exactly as strict. tail_struct at n = 2 000 is written down in advance as a likely FAIL even with the fix. Not frozen, not run, no seeds drawn.

PROPOSED METHOD

V5.1-ZG: a zero-gated composition piece

Per graded channel k: run explain_v5_1 unchanged, then compute the already-validated band BAND_V5_1_PB90 (90% two-sample percentile bootstrap, B = 500; coverage PASSED on composition cells). Then:

if lo_k <= 0 <= hi_k:   c̃_k = 0,     s̃_k = ŝ_k + ĉ_k     # total kept exactly
else:                    c̃_k = ĉ_k,   s̃_k = ŝ_k

This is a pre-test (hard-threshold) estimator. It accepts a little bias when composition is small but real, in exchange for much less made-up composition when there is none. It adds no new knob: 90% and B = 500 are the settings that were already validated. Planned home: the Rust core next to percentile_bands, with a thin Python binding.

EXPECTATIONS · WRITTEN BEFORE ANY RUN

What should happen, and where it can still fail

If the null piece is centred and roughly normal with sd σ, and the band is calibrated, then ungated E|ĉ| = √(2/π)σ ≈ 0.798σ. Gated, E|c̃| ≈ 2φ(1.645)σ ≈ 0.206σ, about 3.9× smaller. Applying that factor to the published means is arithmetic, not a result:

The scored bar is an upper bound, not the mean, so real margins are thinner. The 0.79 δ shift on tail_struct at n = 2 000 makes the band exclude 0 more often than 10%. That cell stays in the suite; dropping it would mean choosing cells from this run. Other risks: the band has never been coverage-checked on structure-only cells or at n = 20 000, and any firing on shape_mixed or the composition cells costs accuracy directly. The pre-registration has to score both.
