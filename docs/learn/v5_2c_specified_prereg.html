The first specified-family pass (seeds 11000–11049 and 11100–11119) finished TRACE on every task and passed the role check, but every rival call failed because scikit-learn was missing, so the accuracy bars could not be scored. The V5.2b pass (seeds 12000–12049 and 12100–12119) had a successful pre-flight and then aborted with zero results: the pre-flight TRACE smoke ran in the parent process and initialized Rayon, after which a forked worker pool deadlocked; the process was SIGKILLed at 16:05 ET. The frozen protocols forbid retrying a spent seed, so this file opens the same test on fresh seeds, keeps the mandatory pre-flight, and adds a spawn-safe harness, a mandatory rehearsal of the parallel pipeline, and a five-minute watchdog. (b) Spawn-safe harness

The V5.2b deadlock happened because the pre-flight called TRACE in the parent process (which started Rayon) and then forked the worker pool. Under this file, the pre-flight runs in a spawned child process. The parent that drives the run never imports TRACE and never calls it. After that child exits, the gate pool — and the rehearsal pool — is created with multiprocessing's 'spawn' start method, from that same parent. Workers are fresh interpreters and may call TRACE; the parent still does not. The default 'fork' start method is not used. A regression test, on a tiny non-gate seed, asserts that this sequence completes within a timeout. That test is not a gate result.

(c) Mandatory rehearsal

Before any gate seed is touched, and after a successful pre-flight, the runner runs the full parallel pipeline — all three methods, the same task function, the same spawn-safe pool, the same watchdog — on two throwaway non-gate seeds, 98 and 97, for every cell (8 tasks, at the same n and p as the gate cells). Rehearsal outputs go to a separate file and never enter scoring. Any failure — a task exception, a method error, a watchdog trip, or the 8 tasks not all finishing — aborts: the gate seeds are not used, they remain unspent, the hypothesis is left undecided, and it is not a fail and not a park.

(d) Watchdog

If no task completes within five minutes, the pass is ABORTED, not failed. The hypothesis is left undecided, and it is not a park. The same rule applies if five minutes pass between completions. During rehearsal, a watchdog trip is a rehearsal failure and does not spend the gate seeds. During the gate, a watchdog trip is also ABORTED (not FAIL), but because the gate has started those seeds are spent, the same way the V5.2b seeds were spent. The 30-minute cap still applies when tasks are completing on time: unfinished cells at the cap are INCOMPLETE, and that inherited rule rejects the hypothesis.

Kill rule. If any cell misses the accuracy bar, fails the role check, or runs out of time, the claim is parked (PARK_V5_2C_SPECIFIED.md), and nothing is re-run, re-seeded, or re-tuned. V5.1’s straight-line claim is unchanged either way, and the v5.2 park stays in place. If the simulator cannot be calibrated, if the pre-flight aborts, if the rehearsal aborts, or if the watchdog trips, the hypothesis is left undecided — it is not redesigned, and it is not a fail.

What this will not claim

  • A PASS does not say a spline, a GAM, or any approximating model works. The location family is correct by construction; that is the point of the test, and its limit.
  • It does not un-park v5.2, and it does not re-run v5.2’s seeds, the first specified-family seeds, or the V5.2b seeds.
  • It does not unseal 9600–9619, and it does not re-run the coverage study.
  • Structure-only cells, mixed cells, speed, and real data are out of scope.
