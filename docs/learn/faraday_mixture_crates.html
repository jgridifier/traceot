Faraday survey: obscure code that could fix TRACE’s mixture gap

Applied reading · 2026-10-26 (America/New_York) · full technical cards in FARADAY_MIXTURE_CRATES.md

The pinned question. What little-known but solid method or code could make TRACE book mix-driven shape change correctly — and compete with CFM on composition cells — while staying fast and glass-box (no neural nets)?

1. Why this matters (RC2 in one picture)

Take two groups with the same bell-shaped noise, centres at −1 and +1. TRACE’s current “average of quantile curves” stays a bell of the same width. Pooling the people (a mixture) makes a wider law. If period B merely has more people far from the centre, the pooled shape moves and CFM sees it; TRACE’s barycenter channels \(k \ge 1\) book nothing. That is RC2 on the v4 board: average of curves ≠ curve of the mixture.

2. What we looked for

  • Classical OT / stats / physics-style numerics (age OK).
  • 1–2 developers, few stars, thin reviews — treated as a feature.
  • Rust preferred for anything we might someday reimplement; foreign code is for borrowing algorithms, not merging crates.
  • Every claim checked against clone / README / tests / license on 2026-10-26.

3. Top three borrows (do these, not a laundry list)

R1 — QAG’s 1-D quantile chart (math only)

QAG (0 stars, no license file — do not vendor) makes one fact unavoidable in code: in one dimension, Wasserstein-2 is flat in quantile coordinates, and the \(p=2\) barycenter is literally the pointwise mean of quantile functions. CFM’s target is different: average the CDFs, then invert.

TRACE hook. Build the model marginal by \(F_{[s,t]}(y)=\mathbb{E}_{x\sim F_s}[F_t(y\mid x)]\), set \(Q_{[s,t]}=F_{[s,t]}^{-1}\), and define the mixing term \(M=Q_{[s,t]}-\bar Q_{[s,t]}\). Run the existing switch game on the marginal quantiles so mixing players receive \(\langle D_M,\Delta M\rangle\). Use the board’s second-order covariance formula as the fast path; use grid inversion as the exact path and the falsifier.

Why v4 may have missed it. A mixing player that still averages quantile bumps stays Lagrangian. QAG pins the numerics to “invert the averaged CDF” — what CFM does on composition cells.

R2 — wnet’s mixture-proportion derivatives (idea only)

wnet (2 stars, MIT, one main developer) is a careful min-cost-flow Wasserstein library that exposes derivatives of transport cost with respect to spectrum mixture proportions, with dual certificates.

TRACE hook. When composition changes bin (or cluster) weights \(\pi_j\), the dual potentials of the 1-D monotone map give \(\partial W^2/\partial\pi_j\). Use that to audit or replace the second-order covariance split when the location spread is not small. Reimplement the 1-D dual form in Rust — do not pull LEMON into the core.

Why v4 may have missed it. v4 defaulted to a Taylor identity. Exact dual derivatives w.r.t. mixture weights are rare in small packages; wnet ships them.

R3 — Entropy balancing + Riesz weights (M4 solvers)

Census EBW (CC0) matches bin moments with minimum-KL weights. krrr does classical kernel Riesz regression for density-ratio-like representers (no neural net).

TRACE hook. For barycenter composition pieces: EBW on TRACE’s own bin indicators (exact under the board’s sufficiency proposition). For the mixture target: least-squares Riesz on bin indicators (+ a few interactions). Drop the logistic period-odds model that balances the wrong moments (RC4).

5. Do not touch

  • GeomLoss / POT — foils only (already well reviewed).
  • SuperInstance OT agent repos — near-duplicate stubs, not careful numerics.
  • UGW / imaging WDL / neural barycenter papers — wrong geometry or neural nets.
  • emd-ring — exact but locked to 9-bin circular HOG.
  • Merging foreign crates into the TRACE core unless tiny, MIT/Apache, and clearly worth it — prefer a page of borrowed math in Rust.

6. The single sharp next experiment

  1. On a two-component location mixture, compute TRACE’s \(\bar Q\) and the Eulerian \(Q_{\mathrm{mix}}\) from the same fitted conditionals.
  2. Check that \(M=Q_{\mathrm{mix}}-\bar Q\) recovers the known shape gap and that H7 composition cells move when \(M\) enters the game.
  3. Compare covariance split vs 1-D dual \(\partial W^2/\partial\pi_j\).
  4. Swap logistic composition weights for EBW on bins; keep the board’s pre-registered bars.

If composition error stays > 2× CFM at \(n=2\times 10^4\), the bottleneck is the conditional model itself — not the game — which is exactly the board’s falsifier.
