1. Why v4 failed (one picture)

v4’s game sat on a Lagrangian average of conditional quantile curves. Composition that spreads locations changes the Eulerian mixture marginal without moving barycenter shape channels. CFM’s object is that mixture; TRACE attributed the wrong object. Board: all ten H7 cells FAIL; ShiftBench mean FAIL on mixed/hetero.

Greenhouse telltale (frozen v4 mixed mean split; from BOARD_V5, not invented): truth \(\approx(0.660,-0.181)\), CFM \(\approx(0.646,-0.174)\), v4 \(\approx(0.238,0.238)\) — a symmetric 50/50 split when composition dominates the mean.

2. Claim

Make the mixture counterfactual the primitive, then run TRACE’s order-free per-feature game on that marginal. Lead papers: Chernozhukov–Fernández-Val–Melly (2013) counterfactual distributions; Kolouri–Park–Rohde cumulative distribution transform (arXiv:1511.03206).

\[ F_{[s,t]}(y)=\mathbb{E}_{x\sim F_s}\bigl[F_t(y\mid x)\bigr], \qquad Q_{[s,t]}(u)=F_{[s,t]}^{-1}(u). \]

Lagrangian residual (what v4 centered on, wrongly as the primary object):

\[ \bar Q_{[s,t]}(u)=\mathbb{E}_{x\sim F_s}Q_t(u\mid x), \qquad M_{[s,t]}(u)=Q_{[s,t]}(u)-\bar Q_{[s,t]}(u). \]

V5 scores the game on \(Q_{[s,t]}\), not on \(\bar Q_{[s,t]}\). Same Rust-core / thin-Python rule; no neural nets.
